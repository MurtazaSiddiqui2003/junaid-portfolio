# Syed Junaid Shah — Portfolio

A bold, editorial portfolio for a fashion and technical designer.

## Built with
- Next.js (App Router)
- JavaScript
- Tailwind CSS
- Framer Motion
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Content to replace before launch
- Profile photo and biography
- Real techpacks, technical flats, and graphic design projects
- Employment history, education, and years of experience
- Email, WhatsApp, and LinkedIn details

Only publish client/employer work with permission. Remove all placeholder content before launch.
